# Maalim — Usage Guide

## For parents
1. **Register** as a Parent (email + password).
2. **Browse** verified tutors on the home page. Filter by subject, area, class, and sort by rating/fee/experience.
3. Open a tutor's **profile** to read their qualification, fee, and parent reviews.
4. Click **Book** — enter student name, class, subject, area, schedule note. The request goes to the tutor as *pending*.
5. When the tutor accepts, attend the sessions; afterwards mark/ask completion.
6. After a **completed** booking, leave a **review** (1–5 stars + comment). One review per booking.

## For tutors
1. Register as a **Tutor**.
2. Open **Dashboard → Edit Profile**: headline, bio, qualification, institution, subjects, classes, areas, fee/hour, and toggle public visibility.
3. Editing resets verification — an admin must re-approve the profile before it appears in public search.
4. In the dashboard, **Accept / Reject** pending booking requests and **Complete** accepted sessions.
5. If the admin rejects your profile, the dashboard shows their note — update and resubmit.

## For admins
1. Sign in with the admin account.
2. **Admin panel → Pending verifications**: review tutor profiles, then Verify (with a note) or Reject.
3. **Users** tab: suspend abusive accounts. Suspended users can't log in and their tutor profile leaves public search instantly.
4. **Stats**: total users/tutors, pending vs verified, bookings, completed GMV (PKR).

## Status flow
```
request → pending → accepted → completed   (parent/tutor may cancel while pending/accepted)
                 └→ rejected
```
